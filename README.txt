Publish:
Upload index.html to your website host's public web root (often public_html, www, or dist).

The mailto link opens the visitor's configured email application; it does not send mail automatically.


GITHUB PAGES QUICK START
1. Create a GitHub repository named nordic-vault.
2. Upload index.html and README.txt to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the published URL shown in Settings > Pages.
